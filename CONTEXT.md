# Pi Prompt Input

Language for reusable instructions and actions invoked from a user's prompt.

## Language

**Prompt template**:
A named, reusable text snippet inserted into a user's prompt.
_Avoid_: Command when referring to text snippets

**Action command**:
A named invocation of application or extension behavior, rather than a reusable text snippet.

**Inline invocation**:
A reference to a prompt template within surrounding prompt text.
